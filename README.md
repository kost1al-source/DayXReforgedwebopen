# DAY X REFORGED

Статический сайт проекта DAY X REFORGED. Для запуска не требуются Node.js, PHP, база данных или сборка.

## Быстрый запуск

Откройте файл `index.html` двойным кликом в браузере. Все локальные стили, скрипты и изображения подключаются относительными путями.

> Для получения актуального статуса Minecraft-сервера сайт обращается к публичному API. Поэтому для работы блока статуса требуется интернет. Остальная страница работает и без него.

## Публикация на обычном хостинге (cPanel / ISPmanager / FTP)

1. Откройте файловый менеджер в панели хостинга или подключитесь по FTP через FileZilla.
2. Перейдите в корневую папку сайта. Обычно она называется `public_html`, `www`, `htdocs` или `httpdocs`.
3. Загрузите **содержимое** этой папки проекта, включая `index.html`, все `.jpg`/`.png` файлы и папку `assets`. Не помещайте их в дополнительную вложенную папку, если сайт должен открываться сразу по домену.
4. Убедитесь, что на сервере существует файл `index.html` именно в корне сайта.
5. Откройте домен в браузере. Если видна старая версия, очистите кэш браузера через `Ctrl + F5`.

Для публикации в подпапке (например, `site.ru/dayx/`) загрузите файлы в эту подпапку и открывайте `site.ru/dayx/`.

## Настройка сервера Minecraft

Адрес сервера задан в начале файла `assets/js/main.js` в объекте `SERVER_CONFIG`:

```js
const SERVER_CONFIG = { host: '...', port: '...', apiUrl: 'https://api.mcsrvstat.us/3/', refreshMs: 45000, timeoutMs: 8000 };
```

Чтобы сменить сервер, замените только `host` и `port`, затем загрузите обновлённый `assets/js/main.js` на хостинг.
Адрес используется только внутри JavaScript-кода для запроса к API и никогда не выводится на страницу.

## Редактирование новостей

Три новости описаны прямо в `index.html` в секции `06 / TRANSMISSIONS`.
Достаточно изменить `news-tag`, заголовок `<h3>` и статус в одном месте — структура ясна по комментариям.

## Примечания

- Не переименовывайте файлы изображений: страница ссылается на их текущие имена.
- Все пути относительные, поэтому сайт работает и при открытии `index.html` с диска, и после загрузки в `www` на любом хостинге.
- Загружайте папку `assets` целиком — в ней находятся CSS и JavaScript. Изображения лежат в корне проекта и также должны попасть на хостинг.
- Хостинг должен обслуживать обычные HTML-файлы; Apache и Nginx подходят без дополнительной настройки.
- YouTube/VK пока отсутствуют и на сайте не отображаются.
